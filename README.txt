Zinrikirin（ボーカル自動切り分け） v0.2.0

■2026-11-10の追加
・波形に音量（dBFS、10ms RMS）をオレンジ線で表示し、無音しきい値を赤い点線で重ねました。
  マウス位置の音量、Shift＋ドラッグした範囲の平均・最大・最小音量も表示します。
  無音しきい値はこの音量で判定します。ブレス候補は音量だけでなく、雑音らしさ（スペクトル平坦度）・
  声らしさ（周期性）・前後との音量差で判定するため、「感度」で調整します。
・ブレス候補で分割する位置を「ブレスの開始」（初期値）／「ブレスの中央」から選べます。
  「開始」では息の音が次の区間の頭に入ります。
・ブレス候補の一覧に、ブレス音量・前後の歌声の音量・落差を表示します。
・「端のドラッグで隣の区間も連動」（初期ON）：区間の端をドラッグすると、接している隣の区間の端も一緒に動きます。
  離れている隣の区間も、ドラッグで食い込んだ分だけ縮みます（同じドラッグ中に戻せば元の位置に戻ります）。
・波形上でCtrl＋クリックすると区間を追加／解除、Ctrl＋Shift＋クリックで範囲をまとめて選択できます。
・S：カーソル位置で分割、Shift+S：選択した連続区間を結合。NumLockがONでも動作します。
・認識モデルに「Qwen3-ForcedAligner（歌詞を合わせる）」を追加。フル歌詞・LRCの文字を各区間へ切り分けて入れます（下記）。
・Qwen3-ASRの日本語指定を、公式実装と同じ「回答の先頭で言語を固定する」方式に修正しました。
  従来は指定が効かず、歌声が英語・中国語で書き起こされることがありました（例：「連れてって」→ "Take me away."）。

■今回の変更
・Qwen3-ASR-1.7Bを追加し、初期選択にしました。Whisperにも切り替えられます。
・公式のTransformers対応版 Qwen/Qwen3-ASR-1.7B-hf を利用します。

■起動・更新（Windows）
1. ZIPを展開します。旧版を更新する場合はアプリを閉じてからファイルを上書きしてください。
   reading_dictionary.json、models、.venv、保存したプロジェクトは消さずに残せます。
2. start.batを実行します。Python 3.11またはuvが必要です。
   基本ライブラリとQwen用ライブラリが不足していれば自動導入します。
   初回のライブラリ導入には時間がかかります。ウィンドウを閉じずにお待ちください。
3. Qwenを選んで認識すると、初回のみ数GB規模のモデルをダウンロードします。
   モデルはmodelsフォルダに保存し、以後は再利用します。初回はインターネット接続が必要です。
   音声・歌詞はローカルで処理します。音声を認識APIへ送信する方式ではありません。

■GPU・CPU
・Qwen実行「自動」：利用可能ならNVIDIA GPU、そうでなければCPUで実行します。
・RTX 2070 SUPERを想定し、GPUはFP16、CPUはFP32です。
  GPUのBF16、FlashAttention 2は使いません。
・start.batはnvidia-smiを検出した場合にCUDA 12.4対応PyTorchを導入します。
  GPUが使えない場合はドライバーを確認し、アプリを閉じてsetup_qwen_gpu.batを実行してください。
・CPU専用にする場合はsetup_qwen_cpu.batを実行してください。CPU認識は遅くなります。
・GPUメモリ不足のときは他のGPU使用アプリを閉じるか、短く分割するか、CPUに変更してください。
・Whisperは従来どおりCPU・int8です。「Qwen実行」の選択はWhisperには影響しません。
・セットアップエラー時もWhisperを使える場合があります。エラー全文を控えてください。
・Qwenは内部で20秒以内に分けて認識します。これは画面やWAV保存の分割位置を変えません。
  長い区間の内部境界で単語を取りこぼす場合は、画面で適切な位置に分割して再認識してください。

■ボーカル抽出済み音源について
Qwen3-ASRは歌声を対象に含み、ボーカル抽出済みWAVをそのまま読み込めます。
ただし日本の歌専用モデルではなく、Whisperより常に高精度とは限りません。
抽出の副作用（音の欠落、金属音、残響）によって誤認識も起きます。
同じ区間を選んでモデルを切り替え、「選択行のみ再生成」で比較できます。

■ブレス候補による分割
1. WAVを開く／ドラッグ＆ドロップで読み込みます。
2. 「ブレス候補も使う（適用前に確認）」をONにします（初期状態はON）。
3. 「自動分割」を押します。
4. 候補一覧で必要な候補を選択し、前後を再生して確認してから「適用」を押します。
   Ctrl／Shiftで複数選択できます。全候補が初めに選択されています。
   選択をすべて解除して適用すると、無音による分割だけになります。
   キャンセルでは現在の区間を変更しません。

最初は「感度50／最短ブレス0.10秒／最短区間0.50秒」をお試しください。
・見逃す場合：感度を上げる（例：65）、または最短ブレスを短くする（例：0.08秒）。
・細かく切れすぎる場合：感度を下げる（例：35）、または最短ブレスを長くする。
・「最短区間」はブレスによる追加分割の両側の長さ制限です。
  無音分割で作られた短い区間を強制的に長くする設定ではありません。
・ブレス候補は音量の落ち込み・雑音に近い周波数特性・前後の有声音を使った推定です。
  学習済みのブレス専用AIではありません。「さ・は」等の子音、残響、抽出ノイズも誤検出します。
・息の音が抽出処理で消えていたり、音量が大きい場合には見逃します。
・初期設定では「ブレスの開始」（息の0.03秒手前）で分割し、息の音を次の区間の頭に含めます。
  従来どおり中央で分けたい場合は「分割位置」を「ブレスの中央」にしてください。息の音は削除しません。
・無音＋ブレスでも長い場合、波形をクリックしてSで手動分割できます。
・結果はCtrl+Zで戻せます。ドラッグで端を動かして微調整する機能も利用できます。
・「ブレス候補も使う」をOFFにすると、従来の無音分割になります。

■Qwen3-ForcedAligner（歌詞を合わせる）
認識モデルで「Qwen3-ForcedAligner（歌詞を合わせる）」を選ぶと、聞き取りではなく
「フル歌詞・LRC」欄の歌詞を各区間へ切り分けて入れます。歌詞の文字そのものが入るため聞き間違いがありません。
区間の位置・長さは変えません（無音・ブレス分割の後に使います）。モデルは Qwen/Qwen3-ForcedAligner-0.6B-hf（約1.8GB）。
・LRC（時刻付き）推奨：各行をその時刻付近の数秒だけで音声に合わせるため、精度が高く速く終わります。
  時刻がずれているLRCは「LRC時刻調整」で直してから実行してください。
・時刻なしの歌詞：まず全区間をQwen3-ASR-1.7Bで認識し、その結果を手がかりに歌詞の位置を決め、
  隣り合う区間の境目をForcedAlignerで調整します。「どぅいどぅい」等の繰り返しや掛け声は外れやすいです。
・歌詞に書かれていない部分（「※くり返し」で省略されたサビ等）は合わせられません。省略せず全文を入れてください。
・短いフレーズ（空白・記号で区切られた12文字以内）は途中で切らず、多く重なる区間にまとめます。
・「選択行のみ再生成」でも曲全体で位置合わせし、選択行だけ書き換えます。
・認識後の照合・補正、ローマ字重複の除去は使いません（歌詞の文字をそのまま使うため）。
・試験結果（ボーカル抽出した4分半の曲・33区間）：LRCありはほぼ全区間で行と区間が一致、処理約12秒（RTX 2070 SUPER）。
  時刻なしは主要な歌詞行はほぼ一致、掛け声の繰り返し部分で数区間ずれました。
・ForcedAlignerだけで曲全体を一度に合わせる方法も試しましたが、歌声では大きくずれたため採用していません。

■フル歌詞・LRC
折り畳み欄にフル歌詞を貼り付けるか、LRC／TXTを読み込みます。
「認識後に歌詞と照合・補正」がONなら、高い一致が得られた部分だけ置き換えます。
LRCは時刻で候補を絞ります。普通の歌詞は本文との類似性で照合します。
曖昧な候補、短い文、読み替えの大きい文は自動補正しません。
空の認識結果を、歌詞だけから埋めることはしません。
本文をまるごと区間へ割り当てたい場合は、下の「Qwen3-ForcedAligner」を選んでください。
「選択行の認識原文」で補正前の文を確認できます。認識のやり直しはCtrl+Zで戻せます。
旧プロジェクトには原文記録がないため、再認識するまで「原文の記録なし」と表示します。
歌詞ヒントの入力内容・折り畳み状態・LRC調整・モデル選択・分割設定はプロジェクトに保存します。

■読み辞書・重複ローマ字
「読み辞書・一括変換」で、私→わたし、明日→あした、英単語→かな等を登録します。
生成前に登録すると優先して読みへ反映します。既存行には選択行／全行へ一括適用できます。
一括適用は歌詞を保持して読み・保存名を更新します（手修正した読み・保存名も置き換わります）。
辞書はreading_dictionary.jsonとプロジェクトに保存します。
一般的な英単語はalkanaで変換します。未知語は辞書登録するか読みを直接編集してください。
「AI認識後に重複ローマ字を除去」はON／OFFできます。
既存行には「選択行の重複ローマ字を除去」を使います。
これは日本語の読みと一致する重複のみを除去する機能で、すべての不自然な記号を消す機能ではありません。

■編集・ショートカット
・波形クリック：区間選択と分割バーの移動。行を選ぶとバーが区間の先頭へ移動。
・Space／全角スペース：選択区間を再生・停止。
・Shift+Space：分割バーから選択区間の終わりまで再生・停止。
・S：バーの位置で「ここで分割」（文字入力中は文字を入力）。
・F2：選択行の歌詞を編集。ダブルクリックでも歌詞・読み・保存名を編集。
・Enter：編集を終えて上下キーで行を選択できる状態へ戻る。
・Ctrl+ホイール：波形を拡大縮小。通常ホイール：横移動。
・Shift+左ドラッグ：時間を計測（秒・msを表示、区間は変更しない）。
・選択区間の左右端をドラッグ：区間を伸縮。隣接区間（除外行含む）との重なりを防止。
・Ctrl+Z／Ctrl+Y：区間・歌詞・読み・保存名・除外状態の取り消し／やり直し。
・除外行はグレー表示。保存時の連番は欠番にします。
・歌詞を編集すると読み・保存名、読みを編集すると保存名を自動更新。

■命名と保存
読みをローマ字にし、母音と「ん」にlを付け、前後にxを付けます。
例：きれい→xkirelix.wav／きれー→xkirex.wav／きっと→xkitox.wav。
助詞は発音に合わせます。長音・促音はファイル名では追加しません。
元WAVのサンプルレート・チャンネル・対応ビット深度を維持して書き出します。
同名ファイルは上書きせず末尾の番号で区別します。元音声は変更しません。
プロジェクトは元WAVを参照するJSONです。元WAVも保管してください。
